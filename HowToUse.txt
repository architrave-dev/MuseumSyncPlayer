Video Player for Museum 운영 안내


[1. 전체 시스템 구조]

이 문서는 서버를 직접 실행하고 여러 기기를 연결해 전시를 운영하는 사용자를 위한 안내입니다.
프로그램 실행, 접속 주소 확인, admin 접속, viewer 접속 순서까지 설명합니다.



[2. 사용법]

0) 모든 기기는 반드시 같은 Wi-Fi에 연결되어 있어야 합니다.
1) 서버용 노트북에서 서버를 실행합니다.
- Visual Studio Code를 실행합니다.
- 하단의 Terminal(명령 프롬프트) 창을 엽니다.
- `npm start` 입력 후 Enter를 누릅니다.
2) 서버용 노트북의 로컬 IP를 확인합니다.
- Windows: Terminal(명령 프롬프트)에서 `ipconfig` 입력
- 확인된 IP에 `:3000` 을 붙인 주소를 사용합니다.
- 예: `http://192.168.0.27:3000`
3) admin 기기 1대를 먼저 접속시킵니다.
- 서버용 노트북에서는 `http://localhost:3000/?adminKey=ilminart` 로 접속할 수 있습니다.
4) viewer 기기들을 접속시킵니다.
- 2번에서 확인한 서버용 노트북 IP로 접속합니다.
- 예: `http://192.168.0.27:3000`
5) 각 viewer에서 영상 번호를 선택합니다.
6) admin에서 재생을 누릅니다.


기본 사용 안내

- viewer 기기들이 모두 접속되고 슬롯 선택까지 끝난 뒤 재생을 시작하는 것이 좋습니다.
- 모바일 기기에서 화면 터치 안내가 보이면 먼저 한 번 터치해 주세요.
- 영상 왼쪽 위 점 색으로 서버 연결 상태를 확인할 수 있습니다.
  초록색: 서버와 정상 연결된 상태
  빨간색: 서버와 연결이 끊어진 상태
- 재생, 처음부터, 구간 이동 등의 제어는 카운트다운 후 함께 시작됩니다.
- 이미 싱크가 잘 맞고 있을 때는 `정지`나 `구간 이동`을 권장하지 않습니다.
- 재생 타이밍이 잘 안 맞는 것처럼 보이면 admin에서 `처음부터`를 눌러 다시 시작하는 것을 권장합니다.



[3. 세부 사용법]

이 섹션은 운영 중 문제가 생겼을 때 확인할 내용을 정리한 안내입니다.

1) 접속이 안 될 때
- 모든 기기가 같은 Wi-Fi에 연결되어 있는지 확인
- 서버용 노트북에서 서버가 실행 중인지 확인
- 접속 주소의 IP가 최신인지 확인
- 서버용 노트북의 로컬 IP가 바뀌지 않았는지 확인

2) admin 접속이 안 될 때
- 주소에 `?adminKey=...` 가 붙어 있는지 확인
- adminKey 오타가 없는지 확인
- 이미 다른 admin이 접속 중인지 확인

3) viewer에서 영상이 안 나올 때
- 슬롯 번호를 제대로 선택했는지 확인
- 화면 터치가 필요한 기기인지 확인
- 새로고침 후 다시 슬롯을 선택해 보기

4) 한 기기만 타이밍이 늦을 때
- 네트워크 상태를 확인
- 먼저 서버에서 `처음부터`를 눌러 전체 재생을 다시 맞춰 봅니다
- 그래도 계속 늦으면 해당 기기만 새로고침 후 다시 접속합니다
- viewer라면 슬롯 선택 후 화면 터치를 다시 진행합니다

5) 구간 이동이 기대대로 안 될 때
- admin이 실제로 버튼을 눌렀는지 확인
- 카운트다운이 보이는지 확인
- 싱크가 이미 잘 맞고 있었다면 불필요한 구간 이동은 피하는 것이 좋습니다
- 잘 안 맞는 상태를 해결하려는 목적이라면 `구간 이동`보다 `처음부터`를 먼저 권장합니다

6) 영상 번호 선택창에서 넘어가지 않을 때
- 숫자를 정확히 입력했는지 확인
- 사용 가능한 번호만 입력했는지 확인
- `Cancel`은 닫기가 아니라 다시 물어보는 동작이므로, 번호를 직접 입력해야 합니다




* 무단 사용, 수정, 재사용 및 가공은 불가합니다.
